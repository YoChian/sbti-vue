# SBTI Vue

这是一个基于原始网页原型重构的 Vue 版本项目。

## 说明

- 原型来源：b站up主蛆肉儿串儿（UID417038183）
- 本项目仅以 Vue 重构，并做了些些许界面和逻辑修改
- 一切权利归原作者所有

## 项目内容

本项目将原始单文件 HTML 原型拆分为 `Vue 3 + Vite` 架构，保留了原测试的主要视觉风格、题库、结果逻辑与文案结构，并对工程组织、数据加载方式和部分界面体验做了调整，方便后续维护与继续开发。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
